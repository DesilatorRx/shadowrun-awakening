Shadowrun 6e Character Creator

Shadowrun Awakening is a free, open-source character generator for Shadowrun, Sixth World (6th Edition). Build a runner in your browser with the priority system: metatype, attributes, magic or resonance, skills and resources, with live point budgets and rule checks at every step.

Features

  • Priority character creation using the Berlin City Edition core rules (2023)
  • Live budgets for adjustment points, attribute points, skill points, karma and nuyen
  • Rule validation: quality limits, skill caps, availability, Essence, incompatible cyberware
  • Metatypes, qualities (including Berlin and Seattle City Edition qualities), skills and specializations
  • Magicians, adepts, mystic adepts and technomancers: spells, adept powers, complex forms
  • Weapons, armor, commlinks, cyberdecks, cyberware and bioware with item details and book page references
  • Printable character sheet, JSON export and import, works on phones

No install and no account. Characters are saved in your browser. Source code on GitHub.
